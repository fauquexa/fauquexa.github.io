What is the Julia set?

Numbers as points. A complex number is just a point on a flat plane: one coordinate across, one up. Squaring it doubles its angle around the centre and squares its distance from the centre.

One rule, repeated. Take a starting point, square it, add a fixed number c, then do the same to the result, again and again: z → z² + c. The point hops around the plane.

Escape or stay. Some starting points race off to infinity; others keep hopping forever without getting far. The Julia set is the border between the two kinds.

The colours. Every pixel is a starting point. Escaping points are coloured by how fast they leave: quickly far from the set, slowly close to the border, which is why the border glows. Points that stay are drawn dark.

Today’s number. c is the number at the top of this panel, and it changes every day. The Mandelbrot set is a map of every possible c: if c is inside it, the Julia set is all one piece; if c is outside, it shatters into infinitely many specks of dust. Today’s c sits near the edge (the cross-hair on the map above), where the shapes are richest.

Endless detail. The rule maps the Julia set onto itself, and near the border it stretches things out: apply it a few times to any tiny piece of the border and you get the whole border back. So every speck holds slightly distorted copies of the whole pattern, which is why the dive never runs out of detail.
